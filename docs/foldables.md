# Fold8 收件箱验收

应用沿用现有姿态探测。打开收件箱后解锁，收合设备时观察当前消息是否仍被选中，以及外屏是否重新要求身份验证。

| 姿态 | 检查 |
|---|---|
| 外屏 | 单栏列表进入详情，复制验证码后剪贴板标成敏感，并在约 60 秒后清除。 |
| 内屏展开 | 展开仍能看到选中详情。列表和详情在双栏中，支持在旁边另开窗口。 |
| 半折桌面 | 控件留在下半屏。值守台默认只显示来源与类别；翻牌需要验证，数字 30 秒后消失。充电或手动打开常亮时，仍应按闲置时间上锁。 |
| 书本姿态 | 两栏避开分隔铰链，详情边缘横滑切换消息。 |
| 分屏 | 长按纯数字验证码可拖出这一段文本。发给自己的入口默认关闭从外部拖入；打开后，拖入的文本能在发送前预览。 |
| 分拣 | 已过滤消息支持跳过和找回。找回有 5 秒撤销窗口。 |
| 配对 | 创建配对，按住显示二维码，手机领取后选择该设备上的两位数字并做生物识别。 |
| 外接键盘 | `Ctrl/⌘+K` 打开命令入口，`Ctrl/⌘+F` 聚焦搜索，`Ctrl/⌘+C` 复制详情中的验证码。 |

实际姿态、铰链排布、窗口与拖放需在 Fold8 上验证。截图校验和构建由 Android CI 执行。
